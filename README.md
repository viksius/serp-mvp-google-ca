# Мониторинг выдачи Google.ca для казино-партнёрок

Я собрала небольшую программу: она берёт топ-10 мобильной выдачи Google.ca по 10 ключам из `keywords.csv`, сохраняет позиции по дням, а нейросеть смотрит каждый найденный сайт и отвечает: подходит ли он для размещения, какие казино на нём упомянуты и как с ним связаться. Результат лежит в `out/report.html` (удобно открыть и посмотреть), а также в Excel, CSV и, по желанию, в Google Таблице.

## Как запустить
Windows: установить Python с python.org (поставить галочку «Add to PATH») и два раза кликнуть `run.bat`. Он откроет Блокнот: туда нужно вписать два ключа (`SERPAPI_KEY` и `ANTHROPIC_API_KEY`) и сохранить. Дальше он сам всё установит, запустит и откроет отчёт. Первый раз занимает 5–15 минут.
Для менеджера есть `Обновить данные.bat`: он спрашивает, что сделать (только обновить отчёт, собрать всё заново или добрать недостающее).

Не Windows: `python -m venv .venv`, затем `source .venv/bin/activate`, `pip install -r requirements.txt`, `cp .env.example .env` (вписать ключи) и `python run.py`.

Повторный запуск в тот же день ничего не дублирует. Тесты (ключи не нужны): `python -m unittest tests`. Google Таблица подключается по инструкции в `apps_script/README.md`.

## Что выбрала и почему
- Сначала я оценила n8n и Apps Script. В n8n собрала рабочий сценарий: ключ → SerpApi (Google mobile, Canada) → разбор строк → разворачивание ссылок Google → запись в Google Таблицу. Apps Script тоже попробовала. Остановилась на Python по двум причинам: ссылки Google /goto приходилось разворачивать с ожиданием и повторами, что в блоках неудобно, и n8n, скорее всего, пришлось бы оплачивать в зависимости от числа запросов и пользователей. Google Таблица осталась как витрина для менеджера.
- Python и SQLite. Не нужен ни сервер, ни облако: всё запускается на любом компьютере одной командой. Базу можно не открывать, всё то же самое есть в отчёте и в Excel.
- SerpApi для выдачи Google: сама не стала бороться с капчей, это отдельная большая задача. Каждый ответ сохраняется, поэтому разобрать его заново можно бесплатно.
- Claude Haiku для разметки сайтов: недорогая и быстрая модель, на каждый сайт один запрос. Чтобы ответы можно было проверять, код сверяет их со страницей: бренд засчитывается, только если он действительно есть в тексте, а контакт берётся из найденных на сайте (почта, страница рекламы или контактов). Если контакта нет, в таблице пишется «Не подтверждён». Сайты, которые не изменились, повторно не анализируются, так что за них не платим.
- Без дублей. Данные за день по ключу заменяются целиком, а новый день добавляется, из этого строится таблица истории позиций. Ссылки очищаю от меток (`utm_` и подобных), иначе один сайт считался бы разными.
- Лимит расходов: по умолчанию не больше 100 запросов к нейросети за запуск.

## Что происходит при сбоях

- Запрос не прошёл: программа пробует ещё несколько раз, а если не вышло, пропускает только этот сайт или ключ, остальные обрабатываются дальше.
- Сайт не открывается (ошибка 403 или защита Cloudflare): решение принимается по заголовку и описанию из Google, в таблице стоит пометка «уверенность низкая».
- Google вместо ссылки показывает «проверяем запрос»: программа ждёт и повторяет только такие ссылки; адрес никогда не угадывается.
- Wikipedia, YouTube и соцсети отсеиваются сразу, без нейросети, чтобы не тратить деньги.

## Сколько стоит один прогон
10 поисков SerpApi (10 кредитов) и около $0.06–0.07 за нейросеть (примерно $0.001 за сайт, около 70 сайтов). Повтор в тот же день стоит почти 0, в следующие дни платим только за новые или изменившиеся сайты. Точные цифры печатаются в конце каждого запуска.

## Результат и качество
В реальном прогоне нашлось 78 уникальных сайтов, 48 подходят для размещения, у 32 из них подтверждён контакт. Я вручную проверила 20 случайных: явных ошибок нет, 3 спорных (сайты-сравнения и газетная подборка). Слабые места: иногда в бренды попадает название самого сайта; у 6 сайтов решение принято только по описанию в Google, потому что страница не открылась; по одному ключу Google вернул всего 2 результата.

## Что сознательно не делала

- Запуск прямо из Google Таблицы по кнопке. Сейчас менеджер запускает обновление двойным кликом по Обновить данные.bat. Для кнопки в таблице код должен работать в облаке, а не на локальном компьютере.
- Обход закрытых сайтов (403, Cloudflare): они размечаются по заголовку и описанию с пометкой «уверенность низкая».
- Определение казино по партнёрским ссылкам: бренды пока берутся только из текста страницы.

## Что сделала бы дальше

- Кнопка «Обновить» в Google Таблице, которая запускает прогон в облаке (например, через GitHub Actions), чтобы у менеджера не нужно было ставить Python.
- Запуск по расписанию раз в день.
- Проход по партнёрским ссылкам.
